# Friday Voice Assistant (Android)

Friday is a voice-first intelligent phone control and cybernetic command-deck assistant built natively for Android using Kotlin and Jetpack Compose.

## Features
- **Holographic Core Visualizer**: Dynamic multi-ring sci-fi reactor core with oscillating scanning beam and live audio level reactive soundwaves.
- **Voice & Typed Command Execution**: Native voice input via speech recognition with fallback to typed command console.
- **Quick Commands Panel**: Instant access to common tasks including junk file scanning, reminders, battery saver controls, and diagnostic queries.
- **Audit Trail**: Real-time logging of executed actions with instant single-tap Undo support.
- **Access Control & Permissions**: Manage Android device permissions (Microphone, Files & Media, Contacts, Notifications, System Settings) with runtime permission requests.
- **Hardware Telemetry**: Real-time simulated HUD telemetry displaying CPU temperature, latency measurements, and system security integrity.
- **Configurable System Settings**: Modal dialog for tuning wake-word detection, haptic feedback, voice synthesis speed, and local audit storage.
